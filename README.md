# Subscription Product Support Desk

## Project Overview

The Subscription Product Support Desk is an AI-powered full-stack application designed to help customers resolve subscription-related problems. It provides a centralized platform for help articles, AI-assisted troubleshooting, service-status information, and support ticket management.

## Objectives

* Help customers find relevant support articles.
* Provide AI-assisted answers using trusted documentation.
* Allow customers to create and track support tickets.
* Help support staff manage and resolve customer issues.
* Provide service-status information and escalation options.

## Main Modules

1. Customer Help Center
2. Customer Ticket Management
3. AI Support Assistant
4. Support Staff Dashboard
5. Authentication and User Management
6. Knowledge Base Management
7. Service Status and Incident Management

## Technology Stack

* Frontend: ReactJS, JavaScript, HTML, CSS
* Backend: Node.js and Express.js
* Database: MongoDB
* Version Control: Git and GitHub
* AI: Retrieval-Augmented Generation (RAG) and AI tools
